# Text Chunking Architecture

Text chunking is performed by `DocumentChunker` in `src/processing/chunker.py`.

## Recursive Character Text Splitter

The chunker utilizes `RecursiveCharacterTextSplitter` with explicit separator priority:

```python
RecursiveCharacterTextSplitter(
    chunk_size=800,
    chunk_overlap=100,
    separators=["\n\n", "\n", ". ", "; ", " ", ""]
)
```

## Metadata Enrichment & Unique `chunk_id`

Every chunk generated by the splitter is enriched with standardized metadata:

```python
chunk.metadata["document_id"] = source_file        # e.g., sample_ev_battery_service.txt
chunk.metadata["document"] = source_file           # e.g., sample_ev_battery_service.txt
chunk.metadata["source"] = source_file             # e.g., sample_ev_battery_service.txt
chunk.metadata["page"] = page_num                  # 1-indexed page number
chunk.metadata["document_type"] = doc_type          # TXT, PDF, DOCX, CSV
chunk.metadata["chunk_id"] = chunk_id              # e.g., sample_ev_battery_service.txt_p1_c0_a1b2c3
```

- **`chunk_id` Format**: `${source_file}_p${page_num}_c${chunk_index}_${uuid_hex[:6]}`
- Guarantees globally unique identifiers across document ingestion runs while preserving deterministic source file and page traceability.
