# 13. Deployment Runbook

## Local setup
1. Install Python dependencies.
2. Configure AWS profile.
3. Initialize Terraform.
4. Validate Terraform.
5. Review plan.
6. Apply with explicit approval.

## AWS verification
1. Check S3 buckets.
2. Confirm Glue catalog entries.
3. Review CloudWatch logs.
4. Run Athena queries.
5. Validate Lake Formation access.
