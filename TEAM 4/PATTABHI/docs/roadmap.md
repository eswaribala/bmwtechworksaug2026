# Roadmap and Day Plan

## Day 1: Understand and design

Confirm KPI definitions and grain, complete PRD and data dictionary, approve AWS architecture, create encrypted S3 bucket, and load representative files.

## Day 2: Build the data foundation

Create Athena database/tables, implement Python validation and transformations, publish Parquet partitions, write KPI/trend/regional SQL, and reconcile sample totals.

## Day 3: Build the BI experience

Create QuickSight dataset and calculated fields, add KPI cards and required visuals, configure controls, drilldown, formatting, and RLS.

## Day 4: Harden delivery

Add unit tests and coverage, structured logging and CloudWatch metrics, GitHub Actions, Terraform review, security review, and complete operations documentation.

## Day 5: UAT and present

Run acceptance scenarios by region, capture evidence, rehearse the live demo, finalize limitations and benefits, and deliver the architecture and code walkthrough.

## Post-MVP

Glue Data Catalog automation, Lake Formation permissions, incremental file manifests, anomaly detection for battery/faults, and optional Snowflake comparison.
