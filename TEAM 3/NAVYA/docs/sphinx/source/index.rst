BMW Enterprise Batch ETL
========================

Welcome to the technical documentation for the BMW Enterprise Batch ETL platform.

This project implements a reusable batch data engineering pipeline for BMW datasets,
including validation, transformation, data-quality handling, Parquet processing,
AWS analytics, FastAPI, and a React dashboard.
