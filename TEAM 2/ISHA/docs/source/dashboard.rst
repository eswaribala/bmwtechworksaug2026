Dashboard and Reporting
=======================

The SQL-based analytics layer feeds directly into Amazon QuickSight for operational reporting.

Key dashboard components include:

- total dealers
- average services per day
- average repair cost
- average capacity utilization
- dealer status distribution
- regional utilization comparisons
- dealer KPI summary table

Dashboard filters
-----------------

The dashboard supports filtering by:

- region
- city
- dealer status
- dealer name

This enables BMW stakeholders to explore service performance by geography and dealer operation profile.
